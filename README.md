# PartyCast Unified

PartyCast превращает один Android-телефон в хост музыкальной комнаты, а остальные телефоны — в слушателей, которые отправляют на хост аудиофайлы, ссылки и команды управления очередью.

## Что есть в этой версии

- Стартовый экран с выбором роли: `Start`, `Host`, `Listener`, `Settings`.
- Более спокойный карточный интерфейс, ближе к мобильному макету PartyCast.
- Хост принимает файлы, ссылки и команды по локальной Wi‑Fi/Hotspot сети.
- В `Settings` можно включить тестовый режим хоста.
- В тестовом режиме на экране `Host` хост может сам добавить ссылку или аудиофайл в очередь без второго телефона.
- Если Яндекс Музыка уже играет, добавленный локальный файл остаётся в очереди PartyCast и не перебивает текущий трек.
- Локальные аудиофайлы воспроизводятся внутри PartyCast через `MediaPlayer`.
- Ссылки Яндекс Музыки можно добавлять следующим треком в очередь приложения Яндекс Музыки через YMQueueController.
- Остальные онлайн-ссылки открываются во внешнем приложении или браузере.
- Диагностика показывает только Wi‑Fi/Hotspot состояние.

## Как проверить на телефоне

1. Откройте проект в Android Studio.
2. Соберите и установите приложение на телефон-хост.
3. На хосте откройте `Host` и нажмите `Запустить хост`.
4. На втором телефоне откройте `Listener`, введите тот же код комнаты и найдите хост автоматически или введите IP вручную.
5. Отправьте аудиофайл или ссылку.

Для Hotspot-сценария включите точку доступа на телефоне-хосте, подключите слушателей к этой сети и используйте кнопку поиска хоста-точки доступа на экране `Listener`.
