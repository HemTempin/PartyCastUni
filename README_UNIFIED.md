# PartyCast Unified Notes

Текущая ветка приведена к упрощённой схеме:

- четыре экрана приложения: `Start`, `Host`, `Listener`, `Settings`;
- карточный мобильный интерфейс вместо технического тестового полотна;
- локальная передача файлов и команд по Wi‑Fi/Hotspot;
- переключаемый тестовый режим хоста для добавления ссылок и локальных аудиофайлов прямо с телефона-хоста;
- локальные файлы больше не стартуют поверх активного воспроизведения Яндекс Музыки;
- очередь PartyCast для локальных файлов и внешних ссылок;
- интеграция с Яндекс Музыкой через YMQueueController;
- внешний fallback для ссылок VK Музыки, Spotify, SoundCloud и неизвестных сервисов.

В активном коде оставлена только текущая рабочая схема:

- локальная комната;
- внешний fallback для онлайн-ссылок;
- настройки Яндекс Музыки;
- диагностика Wi‑Fi/Hotspot.

Сборку в этой папке можно проверять напрямую из Android Studio.
